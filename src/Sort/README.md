# **排序 (Sort)**

本目录包含排序算法的实验说明、接口骨架、公开样例与综合项目要求。

---

## **Baseline（基础实验）**

位于 `Baseline/src/`，学生需要按算法模块完成实现与优化任务：

| 模块分类 | 目录 | 包含算法 |
| --- | --- | --- |
| 插入排序 | `InsertSort/` | 直接插入排序、希尔排序 |
| 归并排序 | `MergeSort/` | 2 路递归归并排序 |
| 基数排序 | `RadixSort/` | 低位优先基数排序 |
| 选择排序 | `SelectSort/` | 直接选择排序、堆排序 |
| 交换排序 | `SwapSort/` | 冒泡排序、快速排序 |

---

## **Project（进阶任务）**
`project/README.md` 给出卡牌对战游戏的排序与牌局调度综合任务。学生需要自行设计实现，并在报告中解释排序算法的选择与性能差异。
