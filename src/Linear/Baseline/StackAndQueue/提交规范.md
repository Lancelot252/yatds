# 提交规范 — 栈和队列

## 文件结构

```
你的学号/
├── Makefile              ← 编译规则（make 默认目标生成 test）
├── src/                  ← 所有源码放这里
│   ├── array_stack.hpp   ← 数组栈声明
│   ├── array_stack.cpp   ← 数组栈实现
│   ├── linked_stack.hpp  ← 链式栈声明
│   ├── linked_stack.cpp  ← 链式栈实现
│   ├── circular_queue.hpp← 循环队列声明
│   ├── circular_queue.cpp← 循环队列实现
│   ├── linked_queue.hpp  ← 链式队列声明
│   ├── linked_queue.cpp  ← 链式队列实现
│   ├── stack_by_queue.hpp← 队列实现栈
│   ├── queue_by_stack.hpp← 栈实现队列
│   └── main.cpp          ← 含 main()，其他文件随意
├── inputs/               ← 自测用例（.txt）
│   ├── case01.txt
│   └── case02.txt
└── outputs/              ← 对应每个 .txt 的正确输出
    ├── case01.txt
    └── case02.txt
```

> **注意**：目录名为 `inputs/` 和 `outputs/`（复数），测试样例使用 `.txt` 后缀。

## 任务 1：栈（Stack）

### I/O 格式

| 操作 | 含义 |
|------|------|
| `PUSH x` | 将 `x` 压入栈顶 |
| `POP` | 弹出并输出栈顶元素 |
| `TOP` | 输出栈顶元素但不弹出 |
| `SIZE` | 输出当前栈内元素个数 |
| `EMPTY` | 输出 `true` 或 `false` |
| `PRINT` | 按从栈顶到栈底的顺序输出当前栈 |

**输出约定**：
- 空栈执行 `POP` 或 `TOP` 时输出 `ERROR`
- 数组栈满时执行 `PUSH` 输出 `ERROR`
- `PRINT` 空栈输出 `EMPTY`，否则空格分隔
- 功能输出后追加性能统计行：`PERF name n=<规模> ops=<操作数> time_ms=<时间>`

### 样例

**输入（`inputs/stack01.txt`）**：
```text
8 3
1 2 3
9
TOP
PUSH 4
PUSH 5
POP
TOP
SIZE
EMPTY
PRINT
POP
```

**输出（`outputs/stack01.txt`）**：
```text
3
5
4
4
false
4 3 2 1
4
PERF array_stack n=100000 ops=200000 time_ms=9.84
PERF linked_stack n=100000 ops=200000 time_ms=21.36
PERF std_stack n=100000 ops=200000 time_ms=8.91
```

## 任务 2：队列（Queue）

### I/O 格式

| 操作 | 含义 |
|------|------|
| `PUSH x` | 将 `x` 加入队尾 |
| `POP` | 删除并输出队首元素 |
| `FRONT` | 输出队首元素但不出队 |
| `SIZE` | 输出当前队列元素个数 |
| `EMPTY` | 输出 `true` 或 `false` |
| `PRINT` | 按从队首到队尾的顺序输出当前队列 |

**输出约定**：
- 空队列执行 `POP` 或 `FRONT` 时输出 `ERROR`
- 数组队列满时执行 `PUSH` 输出 `ERROR`
- `PRINT` 空队列输出 `EMPTY`，否则空格分隔
- 功能输出后追加性能统计行

### 样例

**输入（`inputs/queue01.txt`）**：
```text
6 3
1 2 3
10
FRONT
PUSH 4
PUSH 5
POP
PUSH 6
POP
FRONT
SIZE
EMPTY
PRINT
```

**输出（`outputs/queue01.txt`）**：
```text
1
1
2
3
4
false
3 4 5 6
PERF circular_queue n=100000 ops=200000 time_ms=10.27
PERF linked_queue n=100000 ops=200000 time_ms=24.58
PERF std_queue n=100000 ops=200000 time_ms=9.73
```

## 任务 3：栈与队列互转

### I/O 格式

第一行输入整数 `T`，表示测试场景数。
每个场景第一行输入结构类型：`STACK_BY_QUEUE`、`QUEUE_BY_STACK` 或 `CONVERT`。

**`STACK_BY_QUEUE` / `QUEUE_BY_STACK` 场景**：
```
STACK_BY_QUEUE
n
a1 a2 ... an      ← 栈：从栈底到栈顶；队列：从队首到队尾
m
操作1
操作2
...
```

**`CONVERT` 场景**：
```
CONVERT
n
a1 a2 ... an      ← 原始序列
STACK_TO_QUEUE    ← 或 QUEUE_TO_STACK
```

**输出约定**：
- 每个场景先输出 `CASE t`（`t` 从 1 开始）
- 空结构执行 `POP`/`TOP`/`FRONT` 输出 `ERROR`
- 空结构 `PRINT` 或转换结果为空输出 `EMPTY`
- 功能输出后追加性能统计行

### 样例

**输入（`inputs/interop01.txt`）**：
```text
3
STACK_BY_QUEUE
3
1 2 3
4
TOP
PUSH 4
POP
PRINT
QUEUE_BY_STACK
3
1 2 3
4
FRONT
PUSH 4
POP
PRINT
CONVERT
4
5 6 7 8
QUEUE_TO_STACK
```

**输出（`outputs/interop01.txt`）**：
```text
CASE 1
3
4
3 2 1
CASE 2
1
1
2 3 4
CASE 3
8 7 6 5
PERF stack_by_queue n=100000 ops=200000 time_ms=38.12
PERF queue_by_stack n=100000 ops=200000 time_ms=17.45
PERF vector_based n=100000 ops=200000 time_ms=11.06
```
