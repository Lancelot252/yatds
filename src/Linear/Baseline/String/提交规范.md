# 提交规范 — 字符串

## 文件结构

```
你的学号/
├── Makefile              ← 编译规则（make 默认目标生成 test）
├── src/                  ← 所有源码放这里
│   ├── my_string.hpp     ← 字符串类声明
│   ├── my_string.cpp     ← 字符串类实现
│   ├── match.hpp         ← 模式匹配算法声明
│   ├── match.cpp         ← 模式匹配算法实现（朴素/KMP/nextval）
│   └── main.cpp          ← 含 main()，其他文件随意
├── inputs/               ← 自测用例（.txt）
│   ├── case01.txt
│   └── case02.txt
└── outputs/              ← 对应每个 .txt 的正确输出
    ├── case01.txt
    └── case02.txt
```

> **注意**：目录名为 `inputs/` 和 `outputs/`（复数），测试样例使用 `.txt` 后缀。

## main() 入口

> 测试程序 `test` 需自动读取 `inputs/` 中所有样例，与 `outputs/` 中的标准输出逐行比对，并报告通过/失败。

```cpp
#include <iostream>
#include <fstream>
#include <sstream>
#include <string>
#include "my_string.hpp"
#include "match.hpp"
using namespace std;

int main() {
    // 遍历 inputs/ 目录下的所有 .txt 文件
    // 对每个 case，读取输入 → 执行操作 → 比对输出

    return 0;
}
```

## 三条规则

| 规则 | 说明 |
|------|------|
| 编译 | `make` 后在当前目录生成 `test` 二进制 |
| 输出 | `cout` 纯结果，不加任何提示文字（会被逐字符比对） |
| 自测 | `make test`（或 `make run`）应自动运行所有样例并显示通过/失败 |

## 任务 1：字符串基本实现（MyString）

### I/O 格式

| 操作 | 含义 |
|------|------|
| `PRINT` | 输出当前字符串 |
| `LENGTH` | 输出当前字符串长度 |
| `APPEND t` | 将字符串 `t` 拼接到当前字符串末尾 |
| `SUBSTR pos len` | 输出从下标 `pos` 开始、长度为 `len` 的子串 |
| `FIND t` | 输出子串 `t` 首次出现的下标；不存在输出 `-1` |
| `REPLACE old new` | 将首次出现的子串 `old` 替换为 `new` |
| `COMPARE t` | 与 `t` 比较，相等输出 `0`，小于输出 `-1`，大于输出 `1` |
| `CLEAR` | 清空当前字符串 |

**输出约定**：
- 下标从 `0` 开始
- 越界的 `SUBSTR` 输出 `ERROR`
- 空字符串输出 `EMPTY`
- 功能输出后追加性能统计行：`PERF name n=<规模> ops=<操作数> time_ms=<时间>`

### 样例

**输入（`inputs/string01.txt`）**：
```text
Hello
9
PRINT
LENGTH
APPEND World
SUBSTR 5 5
FIND World
REPLACE World String
COMPARE HelloString
PRINT
LENGTH
```

**输出（`outputs/string01.txt`）**：
```text
Hello
5
World
5
0
HelloString
11
PERF my_string n=100000 ops=200000 time_ms=24.18
PERF std_string n=100000 ops=200000 time_ms=13.76
PERF my_string_reserve n=100000 ops=200000 time_ms=9.42
```

## 任务 2：模式匹配（Pattern Matching）

### I/O 格式

| 操作 | 含义 |
|------|------|
| `NEXT` | 输出模式串的 `next` 数组 |
| `NEXTVAL` | 输出模式串的 `nextval` 数组 |
| `NAIVE` | 朴素算法匹配，输出首次匹配下标；不存在输出 `-1` |
| `KMP` | KMP 算法匹配，输出首次匹配下标；不存在输出 `-1` |
| `KMP_NEXTVAL` | nextval 优化 KMP 匹配，输出首次匹配下标；不存在输出 `-1` |
| `ALL` | 依次输出 `NAIVE`、`KMP`、`KMP_NEXTVAL` 的匹配下标 |

**输出约定**：
- 匹配下标从 `0` 开始
- 数组输出时使用单个空格分隔
- 功能输出后追加性能统计行：`PERF name n=<主串长> m=<模式串长> time_ms=<时间>`

### 样例

**输入（`inputs/match01.txt`）**：
```text
AAAAAAAAAAB
AAAAB
5
NEXT
NEXTVAL
NAIVE
KMP
KMP_NEXTVAL
```

**输出（`outputs/match01.txt`）**：
```text
0 1 2 3 0
0 0 0 0 0
6
6
6
PERF naive n=11 m=5 time_ms=0.018
PERF kmp n=11 m=5 time_ms=0.006
PERF kmp_nextval n=11 m=5 time_ms=0.005
```
