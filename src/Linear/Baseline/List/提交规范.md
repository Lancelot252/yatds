# 提交规范 — 线性表（链表 & 可变数组）

## 文件结构

```
你的学号/
├── Makefile              ← 编译规则（make 默认目标生成 test）
├── src/                  ← 所有源码放这里
│   ├── list.hpp          ← 链表类声明
│   ├── list.cpp          ← 链表类实现
│   ├── vector.hpp        ← 可变数组类声明
│   ├── vector.cpp        ← 可变数组类实现
│   └── main.cpp          ← 含 main()，其他文件随意
├── inputs/               ← 自测用例（.txt）
│   ├── case01.txt
│   └── case02.txt
└── outputs/              ← 对应每个 .txt 的正确输出
    ├── case01.txt
    └── case02.txt
```

> **注意**：目录名为 `inputs/` 和 `outputs/`（复数），测试样例使用 `.txt` 后缀。

## main() 入口

> 测试程序 `test` 需自动读取 `inputs/` 中所有样例，与 `outputs/` 中的标准输出逐行比对，并报告通过/失败。

```cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

// 你的链表 / 可变数组实现
// ...

int main() {
    // 遍历 inputs/ 目录下的所有 .txt 文件
    // 对每个 case，读取输入 → 执行操作 → 比对输出

    return 0;
}
```

### 示例（读取单个测试用例并执行操作）

```cpp
#include <iostream>
#include <fstream>
#include <sstream>
#include <string>
#include "list.hpp"
using namespace std;

int main() {
    // 示例：读取 case01.txt
    ifstream fin("inputs/case01.txt");
    ifstream fout("outputs/case01.txt");

    int n;
    fin >> n;
    LinkedList<int> list;
    for (int i = 0; i < n; ++i) {
        int x;
        fin >> x;
        list.push_back(x);
    }

    int m;
    fin >> m;
    fin.ignore();  // 跳过换行

    ostringstream result;
    for (int i = 0; i < m; ++i) {
        string op;
        fin >> op;
        if (op == "PRINT") {
            auto v = list.to_vector();
            if (v.empty()) result << "EMPTY\n";
            else {
                for (size_t j = 0; j < v.size(); ++j) {
                    if (j > 0) result << " ";
                    result << v[j];
                }
                result << "\n";
            }
        }
        // ... 其他操作
    }

    // 比对 result.str() 与 fout 内容
    // ...

    return 0;
}
```

## 三条规则

| 规则 | 说明 |
|------|------|
| 编译 | `make` 后在当前目录生成 `test` 二进制 |
| 输出 | `cout` 纯结果，不加任何提示文字（会被逐字符比对） |
| 自测 | `make test`（或 `make run`）应自动运行所有样例并显示通过/失败 |

## 链表任务 I/O 格式

测试程序必须支持以下命令式操作：

| 操作 | 含义 |
|------|------|
| `PUSH_FRONT x` | 在链表头部插入 `x` |
| `PUSH_BACK x` | 在链表尾部插入 `x` |
| `INSERT i x` | 在下标 `i` 处插入 `x`，下标从 0 开始 |
| `ERASE i` | 删除下标 `i` 处的元素 |
| `ACCESS i` | 输出下标 `i` 处的元素 |
| `FIND x` | 输出值为 `x` 的第一个元素下标；不存在输出 `-1` |
| `CONTAINS x` | 输出 `true` 或 `false` |
| `SIZE` | 输出当前链表长度 |
| `PRINT` | 从头到尾输出当前链表，空格分隔 |
| `CLEAR` | 清空链表 |

**输出约定**：
- `ACCESS` 越界时输出 `ERROR`
- `INSERT`、`ERASE` 越界时输出 `ERROR`
- `PRINT` 空链表输出 `EMPTY`
- 每个查询操作独占一行输出

## 样例

### 输入（`inputs/case01.txt`）

```text
5
1 3 5 7 9
10
PRINT
INSERT 2 4
ERASE 4
ACCESS 2
FIND 7
CONTAINS 9
PUSH_FRONT 0
PUSH_BACK 10
SIZE
PRINT
```

### 输出（`outputs/case01.txt`）

```text
1 3 5 7 9
4
-1
true
7
0 1 3 4 5 9 10
```

## 自测

```bash
make          # 编译生成 test
./test        # 自动运行所有样例并比对
```

或手动单用例测试：

```bash
make
./test
# 程序应输出：case01: PASS / case02: PASS / ...
```
