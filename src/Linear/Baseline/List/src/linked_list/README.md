# C++ 链表

本目录对应父级 `List/README.md` 中的“链表的基本实现”任务。实际提供给同学们的代码只包含基础测试程序 `testlist.cpp`，链表类的声明和实现需要自行设计与补全。

## 任务目标

你需要用 C++ 完成一个单链表实现，并编写测试程序验证功能。实现时应体现链表由结点组成、结点通过指针连接、内存可以不连续存储等特点。

## 需要完成的内容

- 根据 `testlist.cpp` 的调用方式，创建并实现必要的链表接口，例如 `list.hpp` 和对应的实现文件。
- 定义链表结点结构，结点至少应包含元素值和指向下一个结点的指针。
- 实现链表初始化、插入结点、删除结点、访问结点、查找结点等基本操作。
- 正确管理动态申请的结点内存，尤其要处理析构、清空、删除、拷贝构造和赋值等场景。
- 不要直接使用 `std::list`、`std::forward_list` 等 STL 链表容器作为内部存储结构。
- 在满足 `testlist.cpp` 的基础检查后，继续补充更多功能函数，功能不应只停留在示例中的最小集合。
- 尝试将链表实现为模板类，使其能够支持不同数据类型的存储。
- 编写自己的测试程序，测试应能体现各个函数的行为特点，而不是只做简单调用。

## 与 `testlist.cpp` 的关系

`testlist.cpp` 是仓库给出的基础运行检查，用来约束最基本的链表行为。你的实现需要能够通过该测试程序，同时也要能通过你自己为新增功能编写的测试。

如果你选择沿用 `testlist.cpp` 中的接口命名，需要保证对应的头文件声明、源文件实现和编译方式保持一致。也可以在完成基础要求后加入新的接口，但不要破坏 `testlist.cpp` 已经依赖的行为。

## 规定测试样例格式

父级 `List/README.md` 已给出链表 baseline 的统一输入输出格式。自定义测试程序建议按该格式读取操作序列并输出结果：

注：父级 README 中的测试样例仅用于说明输入输出格式，不代表完整测试覆盖范围，也不是唯一评测数据。学生需要根据该格式自行设计并生成更多测试样例，用于覆盖边界情况和自定义扩展功能。

- 初始数据：先读链表长度，再读从头到尾的元素。
- 操作范围：`PUSH_FRONT`、`PUSH_BACK`、`INSERT`、`ERASE`、`ACCESS`、`FIND`、`CONTAINS`、`SIZE`、`PRINT`、`CLEAR`。
- 输出约定：查询操作逐行输出；越界访问输出 `ERROR`；空链表打印输出 `EMPTY`；布尔值输出 `true` 或 `false`。

仓库给出的 `testlist.cpp` 仍是基础接口检查，不读取标准输入；你的扩展测试应补充上述命令式输入输出格式。
