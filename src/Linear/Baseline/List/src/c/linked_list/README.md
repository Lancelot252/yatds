# C 语言链表

本目录对应父级 `List/README.md` 中的“链表的基本实现”任务。实际提供给同学们的代码只包含基础测试程序 `testlist.c`，链表的接口文件和实现文件需要自行设计与补全。

## 任务目标

你需要用 C 语言完成一个单链表实现，并编写测试程序验证功能。实现时应体现链表由结点组成、结点通过指针连接、内存可以不连续存储等特点。

## 需要完成的内容

- 根据 `testlist.c` 的调用方式，创建并实现必要的链表接口，例如 `list.h` 和 `list.c`。
- 定义链表结点结构，结点至少应包含元素值和指向下一个结点的指针。
- 实现链表初始化、插入结点、删除结点、访问结点、查找结点等基本操作。
- 正确处理动态内存申请和释放，避免删除、清空链表时产生内存泄漏。
- 在满足 `testlist.c` 的基础检查后，继续补充更多功能函数，功能不应只停留在示例中的最小集合。
- 尝试实现一个更通用的 C 语言链表版本，使其能够支持不同数据类型的存储。
- 编写自己的测试程序，测试应能体现各个函数的行为特点，而不是只做简单调用。

## 与 `testlist.c` 的关系

`testlist.c` 是仓库给出的基础运行检查，用来约束最基本的链表行为。你的实现需要能够通过该测试程序，同时也要能通过你自己为新增功能编写的测试。

如果你选择沿用 `testlist.c` 中的接口命名，需要保证对应的头文件声明、源文件实现和编译方式保持一致。也可以在完成基础要求后加入新的接口，但不要破坏 `testlist.c` 已经依赖的行为。

## 提交要求

本部分提交内容应包含：

- 基本链表实现代码。
- 通用链表实现代码。
- 基础测试和自定义测试代码。
- 对程序行为和测试结果的分析，分析应说明你对初始化、插入、删除、访问、查找和内存管理等操作的理解。
