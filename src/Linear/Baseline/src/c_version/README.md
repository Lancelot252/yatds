# 线性结构

本目录保存线性结构 Baseline 的 C 语言任务代码。每个数据结构任务按子目录拆分，目录内通常包含：

- `.h`: 对外接口与类型声明，需要保持函数名、参数和返回值不变。
- `.c`: 主要需要完成的实现代码，需要补全接口声明中的全部操作。
- `test*.c`: 基础测试入口，用于验证实现是否能编译运行并产生预期行为。

完成任务时优先阅读对应子目录的 `README.md`，其中列出了本组需要编写的函数、关键边界情况和验证命令。

## 子目录

- `linked_list/`: 带头结点的单链表，实现查找、插入、删除和整表释放。
- `cursor_list/`: 使用静态数组和游标模拟指针链表，实现空闲表管理和链表操作。
- `linked_stack/`: 使用链表实现栈，实现入栈、出栈、取栈顶和资源释放。
- `array_stack/`: 使用动态数组实现栈，实现容量检查、入栈、出栈和取栈顶。
- `queue/`: 使用循环数组实现队列，实现入队、出队、取队头和循环下标推进。
- `polynomial/`: 使用数组表示多项式，实现置零、加法、乘法和结果输出。
- `common/`: 公共说明目录；当前 C 任务的错误处理直接使用标准库，不再依赖公共错误处理头文件。
