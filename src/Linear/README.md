# 线性表 (Linear)

本项目目录包含了线性表相关数据结构的基础实现与进阶任务代码。

## Baseline (基础实现)

`Baseline` 目录存储了线性表的基本实现，包含 C语言 和 C++ 版本的数据结构：
- **数组 (Array)**
- **链表 (Linked List)**
- **栈 (Stack)**
- **队列 (Queue)**
- **多项式 (Polynomial)** 等

**主要特点：**
- 每个数据结构均包含了基础的操作函数（如插入、删除、查找等）。
- 采用了一套公共的错误处理机制（通过 `fatal.h` 等文件定义的宏来统一输出错误信息并控制程序退出）。
- 这些代码非常适合作为学习数据结构与算法的基础脚手架，也可作为实际项目中的参考实现。

## Project (进阶任务)

`Project` 目录作为完成基础概念学习后的进阶实战任务：
- 旨在探索如何与 AI 协作进行开发。
- 挑战并完成更加复杂的集成测试与扩展应用任务。
