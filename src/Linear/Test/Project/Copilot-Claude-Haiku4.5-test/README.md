## 设计思路

### 1. 数据结构设计

#### ZumaGame 类
- **track**: `std::vector<Ball>` - 轨道上的彩球序列
  - 优点：支持快速的随机访问和插入/删除操作
  - 应用：存储当前轨道状态，支持位置插入和区间删除

- **shootQueue**: `std::queue<Ball>` - 待发射的彩球队列
  - 优点：FIFO 特性符合游戏逻辑
  - 应用：按顺序存储待发射的球

- **history**: `std::vector<GameState>` - 历史状态栈
  - 优点：支持撤销功能
  - 应用：保存每一步操作的游戏状态，允许回溯

#### Ball 结构体
- **color**: 彩球的颜色（使用枚举类型）
- toString()/fromChar(): 颜色与字符之间的转换

#### 消除 (eliminate)
使用扫描算法实现消除：
1. **逐序扫描**: 从左到右扫描轨道
2. **连续计数**: 计算连续相同颜色球的数量
3. **标记删除**: 如果连续3个或以上，标记为删除
4. **循环消除**: 删除后重新扫描，处理连锁消除

```cpp
bool ZumaGame::eliminateSequence() {
    vector<bool> toRemove(track.size(), false);
    
    for (size_t i = 0; i < track.size(); ) {
        size_t j = i;
        while (j < track.size() && track[j].color == track[i].color) {
            j++;
        }
        
        if (j - i >= 3) {
            for (size_t k = i; k < j; k++) {
                toRemove[k] = true;
            }
        }
        i = j;
    }
    
    // 删除标记的球
    ...
}
```

时间复杂度：O(n)，其中 n 是轨道上球的数量

### 使用游戏

1. 打开 `public/index.html` 在浏览器中
2. 在"游戏初始化"部分输入轨道初始状态和待发射队列
3. 点击"初始化游戏"开始
4. 选择位置和颜色，点击"发射球"
5. 观察自动消除和连锁消除
6. 使用"撤销"回到上一步
7. 点击"重置"重新开始

## 游戏规则

1. **消除规则**: 轨道上相同颜色的球如果连续3个或以上，会被自动消除
2. **连锁消除**: 消除后，两侧的球重新连接，如果再次满足消除条件，会自动继续消除
3. **胜利条件**: 轨道和队列中的所有球都被消除
4. **失败条件**: 轨道上的球数超过50个
5. **撤销功能**: 可以回到之前的任何状态
