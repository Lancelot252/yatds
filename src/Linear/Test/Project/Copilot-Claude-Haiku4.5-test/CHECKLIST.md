## 📊 设计指标

### 数据结构
- **轨道**: `std::vector<Ball>` (O(1) 访问，O(n) 插入/删除)
- **队列**: `std::queue<Ball>` (O(1) 入队/出队)
- **历史**: `std::vector<GameState>` (支持多步撤销)

### 算法复杂度
| 操作 | 时间复杂度 | 空间复杂度 |
|------|---------|---------|
| 初始化 | O(n) | O(n) |
| 插入球 | O(n) | O(1) |
| 单次消除 | O(n) | O(n) |
| 连锁消除 | O(n²) | O(n) |
| 撤销 | O(1) | O(1) |
