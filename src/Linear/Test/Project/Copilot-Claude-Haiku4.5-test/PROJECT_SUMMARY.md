## 🔧 技术实现要点

### 1. 数据结构设计
- 使用 `vector` 存储轨道，支持快速的随机访问和插入删除
- 使用 `queue` 存储待发射球，符合 FIFO 特性
- 使用 `vector<GameState>` 维护历史状态用于撤销

### 2. 消除算法
采用**扫描法**实现高效消除：
```cpp
for (size_t i = 0; i < track.size(); ) {
    // 找出连续相同颜色的球
    size_t j = i;
    while (j < track.size() && track[j].color == track[i].color) {
        j++;
    }
    
    // 连续3个以上则消除
    if (j - i >= 3) {
        // 标记删除
    }
    i = j;
}
```
- 时间复杂度：O(n)
- 支持自动连锁消除
