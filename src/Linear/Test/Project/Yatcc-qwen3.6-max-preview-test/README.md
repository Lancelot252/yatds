# 祖玛游戏 — 数据结构综合应用

## 项目概述

本项目使用 C++ 实现了一个经典的祖玛消除游戏，综合运用**双向链表**、**队列**和**栈**三种数据结构。前端采用 HTML/CSS/JavaScript 构建图形化界面，后端使用 C++ 配合 cpp-httplib 提供 HTTP RESTful API。

## 数据结构设计

| 数据结构 | 用途 | 选择原因 |
|---------|------|---------|
| **双向链表** | 彩球轨道 | 频繁在任意位置插入/删除，O(1) 操作 |
| **队列 (std::queue)** | 待发射彩球 | 先进先出 (FIFO)，语义清晰 |
| **栈 (std::stack)** | 撤销历史 | 后进先出 (LIFO)，完美匹配撤销语义 |

## 核心功能

- ✅ 彩球轨道初始化（自定义 / 随机生成）
- ✅ 彩球发射与指定位置插入
- ✅ 自动消除（连续 ≥3 个同色彩球）
- ✅ 连锁消除（消除后连接处再次触发）
- ✅ 撤销操作（基于栈的状态回滚）
- ✅ 游戏胜负判断
- ✅ 计分系统（普通消除 10 分/球，连锁消除 15 分/球）
- ✅ 图形化 Web 用户界面

## 快速开始

### 编译

```bash
make
```

### 运行

```bash
make run
# 或
./zuma_server [端口号]
```

默认端口为 8080，浏览器访问 `http://localhost:8080` 即可开始游戏。

### 清理

```bash
make clean
```

## 游戏玩法

1. **开始游戏**：选择"自定义开始"（输入轨道和队列序列）或"随机开始"
2. **插入彩球**：点击轨道间的竖线，将下一个待发射彩球插入该位置
3. **消除规则**：连续 3 个或以上同色彩球自动消除，可能触发连锁消除
4. **撤销操作**：点击"撤销"按钮回退上一步
5. **胜利条件**：消除轨道上所有彩球且队列为空

## API 接口

| 方法 | 端点 | 说明 |
|------|------|------|
| POST | `/api/init` | 初始化游戏 |
| POST | `/api/insert` | 插入彩球 |
| POST | `/api/undo` | 撤销操作 |
| GET | `/api/status` | 获取游戏状态 |
