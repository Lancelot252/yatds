# 祖玛游戏 - Yatcc-glm-5.1-test

## 项目简介

本项目实现了一个基于数据结构的祖玛游戏，使用 C++ 作为后端，HTML/CSS/JavaScript 作为前端界面。

## 设计思路

### 数据结构选择

1. **彩球轨道 - 链表 (`std::list`)**
   - 原因：需要频繁在任意位置插入和删除彩球，链表的插入/删除操作时间复杂度为 O(1)（已知位置时）
   - 消除操作需要删除连续多个节点，链表可以高效完成
   - 连锁消除后需要重新遍历检查，链表的迭代器不会因删除而失效（除了被删除的元素）

2. **待发射彩球队列 - 队列 (`std::queue`)**
   - 原因：彩球按先进先出顺序发射，队列天然支持 FIFO 操作
   - `push()` 添加彩球到队尾，`pop()` 从队头取出彩球，均为 O(1)

3. **撤销操作 - 栈 (`std::stack`)**
   - 原因：撤销操作需要回退到最近一次操作前的状态，栈的 LIFO 特性完美匹配
   - 每次操作前保存状态快照到栈顶，撤销时从栈顶弹出恢复

4. **道具列表 - 向量 (`std::vector`)**
   - 原因：道具数量固定且较少，向量提供连续内存和快速索引访问

### 核心功能

1. **彩球轨道初始化**：随机生成指定数量的彩球放入链表
2. **彩球发射**：从队列取出彩球，插入到链表指定位置
3. **自动消除**：遍历链表，找到连续3个及以上相同颜色彩球并删除
4. **连锁消除**：消除后重新遍历检查，直到没有可消除的序列
5. **撤销操作**：从栈中弹出上一个状态快照恢复游戏
6. **游戏胜负判断**：轨道清空则胜利，超过最大容量则失败
7. **道具系统**：
   - 随机重排：打乱轨道彩球顺序
   - 炸弹：消除指定位置前后各2个彩球
   - 颏色炸弹：消除所有指定颜色彩球
   - 反转：反转轨道彩球顺序

### 前后端通信

使用 HTTP RESTful API 进行前后端通信：
- `POST /api/init` - 初始化游戏
- `GET /api/state` - 获取游戏状态
- `POST /api/fire` - 发射彩球
- `POST /api/undo` - 撤销操作
- `POST /api/item` - 使用道具

后端使用原生 C++ socket 实现轻量级 HTTP 服务器，无需第三方库依赖。

## 运行说明

### 编译

```bash
# 使用构建脚本
bash build.sh

# 或使用 Makefile
make
```

### 运行

```bash
# 使用运行脚本
bash run.sh

# 或直接运行
./build/zuma_server --port 8080 --public public
```

### 游戏操作

1. 在浏览器中打开 `http://localhost:8080`
2. 点击轨道下方位置标记（↑0, ↑1, ...）将当前彩球插入到指定位置
3. 或在输入框中手动输入位置编号，点击"发射"按钮
4. 使用道具按钮使用各种道具
5. 点击"撤销"按钮回退上一步操作
