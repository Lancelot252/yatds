# 祖玛链表挑战

本项目使用 HTML/CSS/JavaScript 实现用户界面，使用 C++17 实现后端、游戏数据结构和 HTTP 接口。

## 运行说明


然后在浏览器打开：

```text
http://127.0.0.1:8080
```

如果 8080 端口被占用，可以指定其他端口：

```bash
./run.sh 8090
```

## 功能

- 初始化固定关卡，避免完全随机出球导致没有明确终点。
- 点击轨道空位，将待发射队列队首彩球插入指定位置。
- 连续三个或以上同色彩球会自动消除。
- 消除后继续扫描轨道，实现连锁消除。
- 支持撤销上一步操作。
- 胜负判断：清空轨道或达到 120 分胜利；45 回合或队列耗尽失败。
- 道具：炸弹会消除轨道上所有同色彩球；重排会循环调整待发射队列。

## 数据结构设计

- 轨道使用 `std::list<char>`：彩球插入和局部删除频繁，链表适合在中间位置插入和擦除连续区间。
- 待发射彩球使用 `std::deque<char>`：队首出球、队尾追加奖励球都很直接，也支持重排道具。
- 撤销使用 `std::stack<Snapshot>`：每次可改变局面的操作前压入快照，撤销时弹出并恢复。
- 游戏状态封装在 `ZumaGame` 类中，前端只通过 HTTP API 获取 JSON，不直接处理核心规则。

## 核心函数说明

- `insertBall(position)`：从队列头取一个彩球，插入链表指定位置，然后调用 `resolveMatches()` 处理消除。
- `resolveMatches()`：反复扫描链表，找到长度不少于 3 的连续同色区间后删除；删除后重新扫描，从而实现连锁消除。
- `useBomb(position)`：读取指定位置彩球颜色，删除轨道上所有该颜色彩球，再触发一次连锁检查。
- `useShuffle()`：循环移动待发射队列，让玩家获得另一种出球顺序。
- `undo()`：从撤销栈恢复上一步完整快照。
- `updateResult()`：根据轨道、分数、回合和队列情况判断胜利或失败。
