## 设计思路

### 数据结构选择

| 数据结构 | 用途 | 选择原因 |
|---------|------|---------|
| **`std::list<char>`（双向链表）** | 彩球轨道 | 需要在任意位置 O(1) 插入/删除彩球，链表天然支持 |
| **`std::queue<char>`（队列）** | 待发射彩球 | FIFO 先进先出，符合发射顺序 |
| **`std::stack<string>`（栈）** | 撤销操作 | LIFO 后进先出，撤销即回退到最近一次操作前的状态 |

### 核心算法

**消除与连锁消除**：
每次发射后扫描链表，找到连续 ≥3 个同色彩球即消除。消除后重新从头扫描链表，直到没有可消除的连续同色球为止，从而支持连锁消除。

### API 设计

| 端点 | 方法 | 功能 |
|------|------|------|
| `/api/init` | POST | 初始化游戏 `{trackSize, queueSize, maxTrack}` |
| `/api/state` | GET | 获取当前游戏状态 |
| `/api/fire` | POST | 发射彩球到指定位置 `{pos}` |
| `/api/undo` | POST | 撤销上一步操作 |
| `/api/bomb` | POST | 💣 炸弹：消除 pos±2 范围内的球 `{pos}` |
| `/api/shuffle` | POST | 🔀 随机变换下一个球颜色 |
| `/api/pushback` | POST | ⏪ 轨道回退：移除队尾+队首加新球 |
| `/api/rainbow` | POST | 🌈 彩虹球：将指定球变为相邻同色 `{pos}` |

## 功能特性

- ✅ 彩球轨道初始化（随机生成）
- ✅ 待发射队列管理
- ✅ 指定位置插入彩球
- ✅ 自动消除（连续 ≥3 个同色球）
- ✅ 连锁消除（消除后合并再检查）
- ✅ 撤销操作（基于栈的状态保存）
- ✅ 游戏胜负判断（轨道空+队列空=胜利，轨道满=失败）
- ✅ 🔀 随机变换道具
- ✅ ⏪ 轨道回退道具
- ✅ 🌈 彩虹球道具
- ✅ 动态计分系统（消除数 × 连击数 × 10）
- ✅ 精美 HTML5 图形界面
