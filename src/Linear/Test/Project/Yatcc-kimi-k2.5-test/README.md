# 祖玛游戏 - Yatcc-kimi-k2.5-test

## 项目简介

本项目是一个使用 C++ 实现的祖玛游戏，采用 HTML 作为前端界面，C++ 作为后端服务器。

## 数据结构使用

- **链表 (Linked List)**: 用于表示彩球轨道，支持高效的插入和删除操作
  - `BallNode` 结构体实现双向链表
  - 支持 O(1) 时间复杂度的头部/尾部插入
  - 支持任意位置的插入和删除

- **队列 (Queue)**: 用于管理待发射的彩球队列
  - 使用 STL `std::queue` 实现
  - FIFO 特性符合游戏逻辑

- **栈 (Stack)**: 用于实现撤销操作功能
  - 使用 STL `std::stack` 存储游戏状态快照
  - 支持无限次撤销到初始状态

## 功能特性

1. **彩球轨道初始化**: 随机生成初始彩球序列
2. **彩球发射与插入**: 点击插入标记发射彩球到指定位置
3. **自动消除**: 3个或以上连续相同颜色的彩球自动消除
4. **连锁消除**: 消除后两边彩球连接，若颜色相同继续消除
5. **撤销操作**: 支持撤销到上一步操作
6. **游戏胜负判断**: 
   - 胜利条件：清空轨道或达到1000分
   - 失败条件：移动次数用完（50次）
7. **特殊道具功能**:
   - 炸弹：消除指定位置及其周围的彩球
   - 刷新队列：重新生成发射队列

### 运行

```bash
./zuma_server [port]
```

默认端口为 8080，如果端口被占用可以指定其他端口，例如：

```bash
./zuma_server 8888
```

然后在浏览器中打开 `http://localhost:8080`（或指定的端口）

### 使用启动脚本

```bash
./run.sh
```

- `README.md` - 项目说明文档

## 游戏操作说明

1. 点击轨道上的**插入标记**（细竖线）来发射彩球
2. 当三个或更多相同颜色的彩球连在一起时，它们会被消除
3. 消除后，如果两边的彩球颜色相同，会继续发生**连锁消除**
4. 使用**Undo**按钮撤销上一步操作
5. 使用**Bomb**按钮使用炸弹道具
6. 使用**Refresh Queue**按钮重新生成发射队列
7. 点击**New Game**重新开始游戏

## 技术亮点

- 使用纯 C++ 实现 HTTP 服务器，无需额外依赖
- 前端使用原生 HTML/CSS/JavaScript，无需框架
- 游戏状态通过 JSON API 与前端通信
- 支持跨平台（macOS/Linux/Windows）
