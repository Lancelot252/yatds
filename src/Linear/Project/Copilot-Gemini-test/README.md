# 祖玛(Zuma)游戏 - 栈、队列和链表的综合应用

## 项目简介
本项目基于C++（后端核心逻辑）与HTML/JS（前端可视化）实现了简化版的祖玛游戏。
通过结合链表、队列和栈这三种基础数据结构，完美契合了祖玛游戏中“彩球插入与消除”、“弹药补给”、“操作撤销”等核心机制，并借助 `cpp-httplib` 构建了提供 Web API 的轻量级服务端，使得玩家可以拥有良好的图形化用户交互体验。

## 设计思路与数据结构选用 (对应报告：设计思路及数据结构优点)

为了完美契合祖玛游戏的操作模型，本项目在核心类 `ZumaGame` (见 `ZumaGame.hpp`) 中使用了以下三种核心数据结构：

### 1. 链表 (`std::list<char> board`) - 用于表示彩球轨道
* **为什么选择链表？** 祖玛游戏的核心机制是“在任意位置插入彩球”以及“因消除而抹平中间的一段彩球（然后两端重新接合）”。如果使用数组或 `std::vector`，在中间进行插入和删除将导致 $O(N)$ 级别的大规模内存数据搬移操作。而使用双向链表 `std::list`，我们在查找到插入/删除位置后，只需要 $O(1)$ 的时间重置指针即可完成操作。即使连锁消除频繁发生，链表也能保持高效率。

### 2. 队列 (`std::queue<char> next_balls`) - 用于表示待发射的彩球
* **为什么选择队列？** 玩家手中的彩球是一个按顺序补充的弹药库，必须遵守“先进先出 (FIFO)”的原则。每次发射都会消耗最早生成的那颗彩球，而后续生成的彩球会源源不断地从末尾加入，这正是队列的典型应用场景。

### 3. 栈 (`std::stack<Snapshot> undo_stack`) - 用于支持“撤销(Undo)”道具/功能
* **为什么选择栈？** 撤销操作的核心是“后进先出 (LIFO)”。玩家撤销的永远是“最近一次执行的操作”。我们在每次执行插入动作前，将当前的轨道状态和待发射队列打包成快照 (`Snapshot`) 压入栈中；当玩家触发“撤销”时，只要从栈顶弹出最近一次的快照并覆盖当前状态，就能立刻回到上一步。

## 核心功能函数的代码原理解释

1. **状态初始化 `init_game()`**
   * 清空现有的轨道、发射队列和撤销栈，随机生成最初的 10 个轨道彩球以及 5 个待发射彩球，重置游戏状态。

2. **发射与插入 `insert_ball(int index)`**
   * **原理**：首先调用 `save_snapshot()` 将当前状态存档。从 `next_balls` 队列前端出队一个彩球。使用 `std::advance` 将迭代器推进到用户指定的插入索引，调用 `board.insert()` 进行 $O(1)$ 的链表节点插入。插入后，将新的迭代器位置传给 `check_and_eliminate` 检测是否发生消除。

3. **自动消除与连锁消除 `check_and_eliminate(std::list<char>::iterator inserted_pos)`**
   * **原理**：
     * **拓展搜寻**：以刚刚插入的节点为原点，设置左右两个迭代器（指针），向左和向右分别遍历。只要相邻节点的颜色相同，就继续移动迭代器，并增加 `count` 计数。
     * **执行消除**：如果 `count >= 3`，说明满足消除条件。使用链表的 `board.erase(left, right)` 方法快速将该区间的所有节点从内存中抹除。
     * **连锁判定 (递归/迭代)**：当消除发生后，原本被隔开的左右两端在链表中现在变成了相邻的节点。如果它们不为空且内容相同，则对现在的接合位置再次调用 `check_and_eliminate()` 执行递归检测，从而自然而然地实现了连锁消除（Combo）。

4. **撤销道具 `undo()`**
   * **原理**：判断 `undo_stack` 栈是否为空。若不为空，则弹出顶部副本，将其还原给 `board` 和 `next_balls`。本质是基于状态模式(Memento Pattern)的后进先出状态回溯。这也属于题目要求中“增加游戏性和数据结构运用（自己的小道具）”的范畴。

5. **胜负判断 (在前端渲染逻辑中体现)**
   * **原理**：客户端请求 `api/state` 接口拿到轨道字符串，如果轨道长度为 0，页面动态渲染出 **"You Win!"**，表示轨道已被全部清除。

## 扩展：小道具功能的实现可能性
当前已提供 **“时光倒流（Undo，依托于栈机制）”**，如果有需要补充更多道具，可以极其轻松地基于现有数据结构实现：
* **“染色炸弹”**：利用链表的区间消除 `erase`，直接选定一个迭代器向左向右强制消除各2个节点，无视颜色规则。
* **“同色毁灭”**：遍历整个 `std::list`，如果遇到等于目标颜色的节点就调用 `erase`，从而清空轨道上的某一种颜色。
