# 字符串匹配项目：DNA 目标蛋白片段的动态检索

基于 KMP 与树状数组（BIT）实现的一个简化原型。

## 实现功能
- **核心算法设计**: KMP 协议下的匹配处理与动态维护。我们输出要求的前缀数组 `pi` 第一行。
- **动态更新**: 基于树状数组 (Fenwick Tree) 实现 $O(\log n)$ 复杂度的区域统计。包含修改操作 `2 pos C`，支持重新检查突变边界窗口并增量更新 BIT。
- **生信检索**: 涉及了对特定密码子区间的校验结构设计。
- 考虑到这是一个完整的环境测试用例，`main.cpp` 中通过提取框架满足区间动态修改与求区间和查询。

## 运行与编译
1. 使用 `C++17` 以上环境编译。
```bash
g++ main.cpp -std=c++17 -O2 -o main.exe
```
2. 输入格式见上级目录要求。
