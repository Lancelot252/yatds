链表定义与存储方式

链表由一个个节点组成。每个节点分为“值域”和“指针域”：值域保存元素，指针域保存下一个节点的位置。逻辑上相邻的节点，物理内存中可以分散存放。

节点 = 存储节点值 + 存储下一个节点指针
灰色格子表示尚未被链表节点占用的内存空间
1

定义节点

节点保存两个信息：当前元素值，以及指向下一个节点的引用或指针。

2

形成链式关系

每个节点通过指针域连接后继节点，最后一个节点指向 None 或 nullptr。

3

内存可分散

链表不要求节点连续存放，只要指针能找到下一个节点即可。

4

按指针遍历

访问链表时从头节点开始，沿着指针逐个移动到后续节点。

值域 保存当前节点的数据，例如 1、3、2、5、4。
