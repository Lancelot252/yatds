# Graph Project：终端迷宫寻路

> 把迷宫转换成图，分析每个目标的本质，再选择自己在 Baseline 中完成的接口。重点是“问题分析 → 算法选择 → 接口调用 → 结果解释”。

## 迷宫与图建模

| 符号 | 含义 | 进入代价 |
| --- | --- | --- |
| `#` | 墙，不可通行 | — |
| `.` | 普通道路 | 1 |
| `1`–`9` | 数字地形 | 对应数字 |
| `S` / `K` / `E` | 起点 / 钥匙点 / 终点 | 1 |
| `D` | 危险门，始终可通过 | 8 |

```text
#####################
#S#.....#...........#
#.#.###.#.####.####.#
#.#.#.#...#.......#.#
#.#.#.#####.#######.#
#.#.....#...#.....#.#
#.##..###.###.###.#.#
#.#...#1112.....#.#.#
#.#.###.###.#.#####.#
#..1#..D#.#.#...#...#
###.#.###...#####.###
#..9#.#.#K......#.#.#
#2###.#.#.#####.#.#.#
#...4.#.......#....E#
#####################
```

每个非墙格子映射为一个顶点，上下左右相邻的可走格子构成边。是否使用边权以及边权如何定义，取决于任务目标。

## 四个功能任务

| 任务 | 目标 | 建议建模与接口 |
| --- | --- | --- |
| 1 | 从 S 到 E，移动次数尽量少 | 无权图 + `ShortestPath` |
| 2 | 从 S 到 E，总进入代价尽量低 | 非负权图 + `Dijkstra` |
| 3 | 先到 K，再到 E，移动次数尽量少 | 两段无权最短路并拼接 |
| 4 | 先到 K，再到 E，总代价尽量低 | 两段 Dijkstra 并拼接 |

程序界面只显示功能目标，不直接提示算法名称；算法选择必须由你在实现和报告中说明。

## Baseline 接口工具箱

### 无权最短路径

```text
Graph graph = CreateShortestPathGraph(vertex_count, 1);
AddShortestPathEdge(graph, from, to);
ShortestPath(graph, start, dist, prev);
DisposeShortestPathGraph(graph);
```

### 带权最短路径

```text
WGraph graph = CreateDijkstraGraph(vertex_count, 1);
AddDijkstraEdge(graph, from, to, weight);
Dijkstra(graph, start, dist, prev);
DisposeDijkstraGraph(graph);
```

BFS、DFS、Prim 和 Kruskal 接口可用于自选扩展；本项目的四个核心任务不要求使用 MST。

## 实现、运行与报告

### 需要完成

- `BuildUnweightedMazeGraph`：建立无权迷宫图。
- `BuildWeightedMazeGraph`：按进入目标格子的代价建立带权图。
- `RebuildPath`：沿 `prev[]` 回溯并翻转路线。
- 四个 `Find...` 功能函数：建图、调用接口、拼接并整理结果。
